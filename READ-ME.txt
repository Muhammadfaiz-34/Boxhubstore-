BOX HUB STORE — PORTABLE WEBSITE

Extract the complete ZIP, then open index.html in a web browser.
No web server, installation, or internet connection is needed for the catalog or photos.
Keep the assets folder, styles.css and app.js beside index.html.

For sharing a single file, use Box-Hub-Store-Open-Me.html. It contains the website,
styles, scripts, catalog and all 21 photos. No separate image folder is needed.
The single-file version uses system font fallbacks so it works offline.
On phones, choose Open in Browser if the Files app only shows a static preview.

Hosting: upload the extracted website files to a static web host.
Quote sending and custom-domain DNS remain unconfigured. The project form downloads
an inquiry brief; it does not send it. Set confirmed business contact details before launch.
